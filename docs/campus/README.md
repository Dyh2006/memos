# 拾光校园

基于 [Memos](https://github.com/usememos/memos) 的校园失物招领扩展，Fork 地址：https://github.com/Dyh2006/memos 。保留原项目 MIT LICENSE。本目录说明新增能力，不替换上游品牌说明。

## 已编写的功能

访问 `/campus`，也可点击原页面顶部的“拾光校园 · 失物招领”。登录后发布寻找失物或拾到物品记录，填写物品、类别、地点、发生日期与说明。按关键词、日期范围、类型、类别及状态筛选。发布者可将状态更新为待认领、认领中、已归还，认领者通过原有详情页留言联系。

记录通过原有 Memo API 保存，使用 PROTECTED 可见性和 campus-lost-found 标签。结构化数据保存在 campus-v1 代码块中，不新增数据库表或后端服务。原有 Memo 编辑器仍可编辑这些记录，格式损坏时校园页跳过该记录，可在原笔记中修复。第一版适合小范围试点，记录量增大后应迁移至服务端字段与查询。

CSV 导出筛选后的记录，不导出身份或补充说明。分页未全部加载时禁止导出，避免漏记；列表显示已加载范围，不能误称全校统计。导出包含 Excel UTF-8 BOM、引号转义及公式注入防护。统计是发布记录数，同一物品的寻找和拾到记录可能重复，不能直接解释为找回率。

## 来源与新增边界

原项目：用户与登录、Memo API、数据库、权限、笔记详情与评论、通用导出、运行框架。
新增：校园页和入口、结构化表单、校园筛选、发布者状态控件、范围明确的 CSV 导出与计数、序列化及导出测试。
尚未实现：匿名发布、学校统一身份认证、自动匹配、认领证据审核、状态审计日志、防并发覆盖、全校运营数据。

PROTECTED 仅表示本站登录用户可见，不能证明学校身份。试点前由管理员管理注册和账号发放。不要填写证件号、手机号和家庭住址。匿名需要后端统一隐藏作者信息，不应仅在页面隐藏姓名。

## 开发与运行

按仓库根目录 AGENTS.md 所需版本准备 Go 1.27、Node 24 和 pnpm。

```bash
cd web
pnpm install --frozen-lockfile
pnpm release
cd ..
go build -o memos ./cmd/memos
./memos --port 5230 --data ./campus-data
```

Windows 运行 `memos.exe --port 5230 --data ./campus-data`。访问 http://localhost:5230/campus 。不要直接运行上游 Docker 镜像并认为它包含本 Fork 的功能。试点需自行备份数据目录及附件；当前没有提供已验证的单命令安装包。

## 验收脚本

1. 账号 A 发布拾到水杯，账号 B 应可查看并留言。
2. 未登录访问不能读取 PROTECTED 记录；账号 B 不能通过 API 修改 A 的记录。
3. A 更新状态，刷新后应保持更新结果。
4. 按图书馆、类别、日期筛选，导出行数与界面一致。
5. 超过一页时先加载剩余记录再导出，模拟失败不应导出缺页结果。
6. 重启服务后记录仍保留。

本地静态检查和前端构建不等于上述真实后端验收。交付前应在安装 Go 的环境完成双账号验证。
